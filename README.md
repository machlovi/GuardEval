
# GuardEval

GuardEval is a unified multi-perspective benchmark dataset designed for both training and evaluation of LLM moderators.

- **Paper:** [GuardEval Paper](https://dl.acm.org/doi/10.1145/3815159)
- **Hugging Face Model:** [GGuard](https://huggingface.co/Machlovi/GGuard)
- **Dataset:** [GuardEval Dataset](https://huggingface.co/datasets/Machlovi/GuardEval)
